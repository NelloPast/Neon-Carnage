1. Описание проекта
Neon Carnage — это небольшая 2D-игра в жанре Top-Down Shooter с видом сверху. Действие игры происходит в вымышленном американском городе в конце 1980-х годов.
Игрок управляет персонажем, который участвует в противостоянии уличных группировок. Основная задача — проходить уровни, сражаться с противниками и выполнять поставленные задания.
Визуальный стиль проекта будет выполнен в пиксельной графике с яркими неоновыми цветами и атмосферой 1980-х годов. Игра будет вдохновлена Hotline Miami, но получит собственных персонажей, уровни и сюжет.

2. Цель проекта
Создать небольшую, законченную 2D-игру, в которой игрок сможет управлять персонажем, стрелять, сражаться с противниками и проходить несколько уровней.

3. Основные функции игры
В проект планируется включить:
Управление персонажем с помощью клавиш WASD.
Прицеливание с помощью мыши.
Стрельбу из оружия.
Противников с простым искусственным интеллектом.
Систему здоровья игрока.
Возможность проиграть и начать уровень заново.
Условие победы после уничтожения всех противников.
Несколько небольших игровых уровней.
Главное меню и интерфейс игры.
Звуковые эффекты и фоновую музыку.

4. Планируемые уровни
Уровень 1 — Склад. Небольшая карта для знакомства с управлением и основными механиками.
Уровень 2 — Ночной клуб. Более сложная карта с большим количеством противников и препятствий.
Уровень 3 — База банды. Финальный уровень с повышенной сложностью.
5. Технологии и инструменты

Предварительно планируется использовать:
Godot 4 — игровой движок.
GDScript — язык программирования.
Git — контроль версий.
GitHub — хранение проекта и совместная работа.
GitHub Projects — распределение и отслеживание задач.
Piskel или Aseprite — создание пиксельной графики.
ChatGPT — помощь с программированием, поиском ошибок и документацией.
